DARK SKIN-ONLY SHIRT VARIANTS

This archive retains the original shirt assets unchanged and adds dark_skin_only variants for:
  camo, fire, ice, original, purple

Each theme contains:
  dark_skin_only/25_percent_darker/
  dark_skin_only/50_percent_darker/
  dark_skin_only/75_percent_darker/

Each level includes the same 16 frame filenames as the original. Left/right directional frames
and the combined sprite sheet/preview have the hand skin tones darkened by 25%, 50%, or 75%.
The front/back frames are copied unchanged because no exposed hand skin is visible there.
Only identified hand skin-tone pixels are recolored; shirt/sleeve pixels, outlines, transparency,
image dimensions, and pixel positions are preserved.

Brightness multipliers applied to the hand skin RGB values:
  25_percent_darker = 0.75x
  50_percent_darker = 0.50x
  75_percent_darker = 0.25x

Original assets remain at their original paths; the variants are additional files.
