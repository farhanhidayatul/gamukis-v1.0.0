Shirt hand skin darkness variants

The original files supplied in shirt_updated.zip are preserved unchanged. The added assets are stored under:
shirt/<theme>/dark_skin_only/<level>/

Each level contains the same sprite-sheet filename and frames/ PNG filenames as the base theme.

Levels (applied only to hand skin fill/mid-shadows):
- 25_percent_darker: RGB factor 0.75 (75% brightness retained)
- 50_percent_darker: RGB factor 0.50 (50% brightness retained)
- 75_percent_darker: RGB factor 0.25 (25% brightness retained)

Sleeves/clothing, deep outlines, alpha/transparency, dimensions and original base assets are preserved. Reference skin regions come from the original theme and only pixels matching the reference colors at the same coordinates are changed in the recolored themes, avoiding darkening fabric with similar colors.
Themes: camo, fire, ice, original, purple.
